# 🧾 AI 智慧刷卡簽單 & 收據自動辨識整理工具 (Google 試算表連動版)

本專案依照使用者需求與完整對話演進歷程全新升級開發。結合 **Google Gemini 多模態 AI 視覺模型**、**當日即時外幣匯率換算** 與 **Google 試算表 (Google Sheets) 雙向連動**。

---

## ✨ 核心功能與需求特點對應

| 需求項目 | 功能實作特點 |
| :--- | :--- |
| **自動辨識簽單/收據** | 支援手機拍照、JPG、PNG、WebP、PDF，自動進行高精確度 OCR 辨識。 |
| **日期與時間擷取** | 自動結構化解析為標準 `YYYY-MM-DD` 與 `HH:MM`。 |
| **商店名稱中英雙語** | 自動識別商戶原始名稱與繁體中文名稱；**表頭具備獨立下拉選單，可一鍵全數切換中文或原文**。 |
| **商品品項與數量** | 完整擷取商品名稱（支援繁中/原文切換）、購買數量 (Quantity) 與單價/小計 (Price)。 |
| **折扣折讓負數標註** | **依 Turn 5 需求：若品項為促銷、折扣、折讓、優惠券折抵，金額自動標記為負數 (如 `-50`, `-4.00`)**，並給予紅色醒目標籤。 |
| **當日即時台幣匯率** | 自動呼叫即時匯率 API，依執行當天匯率將外幣 (USD, JPY, EUR 等) 自動換算為新台幣 (TWD)。 |
| **自動轉存 Google 試算表** | 點擊「轉存到 Google 試算表」後，**互動視窗主動詢問您要儲存到哪一個檔案 (Spreadsheet) 以及哪一個工作表 (Worksheet 分頁)**！ |

## 🚀 快速開始使用 (網頁版 - 推薦)

本專案採用 **單一獨立網頁架構 (`index.html`)**，免安裝複雜伺服器環境，以任何現代瀏覽器（Chrome、Edge、Safari 等）雙擊即可開啟！

### 步驟 1：開啟網頁
直接用瀏覽器開啟 `receipt_ai_sheets/index.html`。

### 步驟 2：設定 Gemini API Key
1. 點擊右上角 **「API & 試算表設定」**。
2. 填入您的 Google Gemini API Key（可前往 [Google AI Studio](https://aistudio.google.com/apikey) 免費獲取）。
3. 預設推薦模型為 `gemini-3.1-flash-lite`（最新超低延遲首選，高性價比 & 極速辨識），並支援切換至成熟穩定的 `gemini-2.5-flash`。
> 💡 貼心提醒：如果手邊暫時沒有 API Key，可直接在畫面上點選 **「載入完整範例資料 (免金鑰體驗)」**，立即體驗中英切換、負數折抵與匯率試算！

### 步驟 3：辨識簽單與收據
- 點擊上傳區域或直接拖曳圖片/PDF 檔案。
- 支援手機/平板瀏覽器直接點擊拍照。
- 辨識完成後，即刻在表格中看到商店名稱、商品明細清單、原幣總額、折合台幣、日期時間與分類標籤。

### 步驟 4：切換語言與核對
- **商店名稱切換**：在表頭的 `商店名稱` 旁下拉選單，切換「繁體中文」或「原文名稱」。
- **商品名稱切換**：在表頭的 `商品名稱 / 明細` 旁下拉選單，切換「繁體中文」或「原文名稱」。
- 折扣折讓項目以紅底標示負數金額。

## 📊 Google 試算表轉存連動教學 (詢問檔案與工作表)

點擊畫面右下角綠色的 **「轉存到 Google 試算表...」** 按鈕，系統會彈出互動對話框：

### 1️⃣ 詢問我要存在哪一個檔案？
- **方式 A (從清單選取)**：點擊「登入 Google 帳號」，系統會透過 Google Drive API 列出您雲端硬碟裡所有的試算表檔案名稱供您點選。
- **方式 B (建立新檔案)**：點擊「＋ 建立新的 Google 試算表」，輸入新名稱（例如 `2026年11月簽單收據明細`），系統會立即在您的雲端硬碟自動建立並選取！
- **方式 C (貼上網址/ID)**：直接將任何 Google 試算表網址貼入輸入框中。

### 2️⃣ 詢問我要存在那一個工作表 (分頁)？
- 系統會即時連線讀取該試算表中**現有的所有分頁**（例如 `工作表1`、`11月帳目`、`出差報帳` 等），以清晰下拉選單供您選擇！
- 亦可選擇 **「＋ 建立新工作表分頁...」**，輸入新名稱（或點擊「當月命名」自動填入如 `2026-11 簽單明細`），系統將自動為您新增該工作表分頁！

### 3️⃣ 寫入設定與格式化
- **寫入語言**：可選遵循畫面目前表頭所選語言、固定繁體中文、固定原文或中英雙語並列。
- **展開模式**：
  - **商品明細逐項展開 (推薦)**：每一商品品項獨立一行，明細完整。
  - **每筆簽單一行**：商品品項合併為文字摘要。
- **自動表頭**：若目標工作表為全新空白，系統會自動在第一列加入專業的標題欄位。

## 🛠 免 GCP OAuth 的快速連線法：Apps Script (GAS) 模式

若您不想申請 Google Cloud Console 的 OAuth Client ID，只要使用隨附的 `google_apps_script.js`：

1. 打開您的 Google 試算表。
2. 點擊選單 **「擴充功能」->「Apps Script」**。
3. 貼上 `google_apps_script.js` 的完整內容。
4. 點選右上角 **「部署」->「新部署」**：
   - 類型：**網頁應用程式 (Web App)**
   - 誰可以存取：**任何人 (Anyone)**
5. 複製產生的 `https://script.google.com/macros/s/.../exec` 網址。
6. 在網頁的「API & 試算表設定」選擇「Apps Script Webhook」，貼上該網址即可完成連線！

## 🐍 Python 批次處理版本 (`receipt_to_sheets.py`)

如果您偏好使用終端機命令列批次辨識：

```bash
# 執行腳本 (會自動提示輸入圖片路徑與 API Key)
python receipt_ai_sheets/receipt_to_sheets.py

# 或直接帶入圖片路徑
python receipt_ai_sheets/receipt_to_sheets.py "C:\path\to\receipt.jpg"
```

腳本會：
1. 自動辨識並在終端機漂亮輸出商店、品項、負數折扣與折合台幣金額。
2. 互動提示詢問：
   - `請輸入 Google 試算表檔案 ID 或完整網址:`
   - `請問要儲存到哪一個工作表 (分頁)？`
3. 自動將擷取結果精確寫入並輸出備用 CSV。
