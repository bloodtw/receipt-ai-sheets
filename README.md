# 🧾 AI 智慧刷卡簽單 & 收據自動辨識整理工具 (Google 試算表連動版)

本專案結合 **Google Gemini 多模態 AI 視覺模型**、**交易當日歷史外幣匯率換算** 與 **Google 試算表 (Google Sheets) 雙向連動**。

---

## 📋 標準 14 欄擷取與輸出順序（由左至右）

無論在網頁表格預覽、匯出 CSV 或直接轉存至 Google 試算表，皆固定由左至右依序擷取與填入以下 14 個欄位：

| 欄位順序 | 欄位名稱 | 擷取與處理邏輯 |
| :---: | :--- | :--- |
| **1** | **商店名稱 (中文)** | AI 自動翻譯或辨識之繁體中文商店名稱 |
| **2** | **商店名稱 (原文)** | 簽單或收據上之原始商店名稱 |
| **3** | **商品名稱 (中文)** | AI 自動翻譯或辨識之繁體中文品項名稱 |
| **4** | **商品名稱 (原文)** | 簽單或收據上之原始品項名稱 |
| **5** | **商品數量** | 該品項之購買數量（預設為 `1`） |
| **6** | **商品價格** | 該品項之價格；**若為折扣、折讓、優惠券折抵則自動記為負數（如 `-50`）** |
| **7** | **總金額** | 該筆簽單之原幣交易總金額 |
| **8** | **幣別** | 交易幣別代碼（如 `TWD`, `USD`, `JPY`, `EUR` 等） |
| **9** | **台幣金額** | 依消費日期當天外幣匯率自動換算之新台幣金額 (`總金額 × 匯率`) |
| **10** | **日期** | 交易日期（標準化為 `YYYY-MM-DD`） |
| **11** | **時間** | 交易時間（標準化為 `HH:MM`） |
| **12** | **分類** | 簡單分類三選一：**`餐飲`**、**`交通`**、**`購物`** |
| **13** | **購買人** | 固定**留白**（`""`），方便後續於試算表自行標註 |
| **14** | **匯率** | 依簽單交易日期當天查詢之 **外幣 vs 台幣** 歷史匯率（本國貨幣 `TWD` 為 `1`） |

## 🚀 快速開始使用 (網頁版 - 推薦)

1. **開啟線上網站或本機網頁**：
   - 線上網址：[https://bloodtw.github.io/receipt-ai-sheets/](https://bloodtw.github.io/receipt-ai-sheets/)
   - 或直接以瀏覽器開啟本機 [`receipt_ai_sheets/index.html`](file:///d:/Google%20Antigravity/AI%20Tools/receipt_ai_sheets/index.html)。
2. **設定 Gemini API Key**：
   - 點擊右上角 **「API & 試算表設定」**。
   - 填入您的 Google Gemini API Key（可前往 [Google AI Studio](https://aistudio.google.com/apikey) 免費獲取）。
   - 預設推薦模型為 `gemini-3.1-flash-lite`（最新超低延遲首選，高性價比 & 極速辨識），並支援切換至成熟穩定的 `gemini-2.5-flash`。
   - 💡 如果手邊暫時沒有 API Key，可直接在畫面上點選 **「載入完整範例資料 (免金鑰體驗)」**。
3. **上傳並轉存 Google 試算表**：
   - 點擊上傳或拖曳簽單圖片 / PDF 檔案。
   - 辨識完成後，點擊右下角綠色的 **「轉存到 Google 試算表...」**，選擇目標**試算表檔案**與**工作表分頁**即可一鍵寫入 14 欄完整資料！
